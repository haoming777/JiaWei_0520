# 相机开关配置工具（CameraSwitchTool）

给客户现场用的独立小程序：切换各相机的**工位启用（ActiveCam1-5）**与**AI 推理开关（IFRunCamera1-5）**，
客户无需直接编辑 `setup.ini`。

## 功能

- 扁平化 WPF 界面，每个开关带检测项目说明（管内异物 / 管盖有无 / 管口圆度 / 正面工号缺失 / 细分缺陷）
- **加密狗验证**：启动必须插狗（无狗打不开）；运行中拔狗自动锁定保存/重启并弹窗警示，插回自动恢复
- 保存时自动备份 `setup.ini.camswitch.bak`（滚动覆盖，位于 setup.ini 同目录）
- 保存成功后提示是否**立即重启主程序**（或主程序未运行时提示是否启动）
- 防呆校验：至少需启用一个工位（与主程序 MainFrm 的防呆逻辑一致），全部关闭时禁止保存
- 主程序运行状态实时显示（每 2 秒刷新）
- 未保存修改提示：状态栏黄点 + 退出确认 + 放弃修改需二次确认
- 单实例运行（互斥锁），防止重复打开同时写 ini

## 操作日志

每次保存/放弃/重启都会记录到 **`Logs\CameraSwitchTool.log`**，与主程序日志同在
`bin\Logs\` 目录下，文件名与主程序日志（`app_*.log`、`crash_*.log`）区分，不会撞名。
日志为 UTF-8（带 BOM），记事本可直接打开。

## 构建

- Visual Studio 2017+ 打开 `CameraSwitchTool.sln`，Release 编译即可
- 输出路径已配置为 `..\..\bin\`，编译产物直接落到主程序 bin 目录
- 无任何 NuGet 依赖，目标框架 .NET Framework 4.7.2（与主程序一致）

## 部署

将 `CameraSwitchTool.exe` 复制到主程序 `VisionMeasure.exe` 所在目录（bin\），双击运行。
工具会自动定位同目录的 `setup.ini`；若主程序在运行且同目录无 setup.ini，会退而取主程序进程目录。

## 注意事项

- **管理员权限**：主程序以管理员运行，本工具也以管理员运行（启动时会弹 UAC 确认，属正常现象），否则无法关闭/重启主程序
- **加密狗**：本工具与主程序（v28 起）均要求插入 XL 加密狗才能使用，狗由现场工程师保管
- 所有开关**重启主程序后生效**（主程序对 ini 有缓存，运行期不重读）
- 备份文件 `setup.ini.camswitch.bak` 每次保存会被覆盖，如需多版本备份请自行另存
