# v7 版本现场部署说明（2026-08-20）

版本标识：`2026-08-20-v7`（程序启动日志里可见，确认现场跑的是新版本）

## 一、功能清单

1. **设备状态互锁**：程序周期读取设备状态（西门子 `DB1000.DBW232` INT / 汇川 `M7070` INT），值=4 为自动、其他为手动。
   - 自动状态下：禁止进入"相机设置"界面；禁止打开"实时取像"；
   - 实时取像进行中切到自动 → 自动停止实时；
   - 相机设置界面打开期间切到自动 → 弹窗提示并自动关闭界面。
2. **气缸状态日志**：读取气缸状态（西门子 `DB1000.DBX234.0` / 汇川 `MX7074.0`，TRUE=禁用 FALSE=启用），**状态变化时**输出日志。
3. **实时取像回报位**：实时取像启动时向西门子写 `DB1000.DBX72.0`(正面)/`72.1`(反面)=TRUE，停止时复位 FALSE（Bool，TRUE=打开实时显示，FALSE=关闭）。

## 二、日志搜索关键字（在 Logs\app_日期.log 里搜索）

| 关键字 | 含义 |
|---|---|
| `【设备状态】` | 设备模式变化（自动/手动切换） |
| `【气缸状态】` | 气缸禁用/启用状态变化（`[S7-1200]`/`[Modbus]` 标识是哪一路 PLC） |
| `【互锁】` | 自动模式下被拦截的操作（进入相机设置/打开实时取像） |
| `【实时回报】` | 实时取像回报位写入记录 |

注意：若日志里出现"读DB1000.DBW232/DBX234.0失败"或"读M7070/MX7074.0失败"的警告，说明 **PLC 程序还没加这些地址**——互锁功能会不生效（但绝不影响生产主流程），请通知 PLC 工程师更新程序。

## 三、PLC 程序需要新增的地址

| 地址 | 类型 | 说明 |
|---|---|---|
| DB1000.DBW232 | INT | 设备状态：4=自动，其他=手动 |
| DB1000.DBX234.0 | BOOL | 气缸状态：TRUE=禁用，FALSE=启用 |
| DB1000.DBX72.0 | BOOL | 相机1实时回报位（程序写，TRUE=正在实时显示） |
| DB1000.DBX72.1 | BOOL | 相机2实时回报位（程序写） |
| M7070 | INT（汇川） | 设备状态：4=自动，其他=手动 |
| MX7074.0 | BOOL（汇川） | 气缸状态：TRUE=禁用，FALSE=启用 |

## 四、快速调整"正面是相机1还是相机2"（改 setup.ini，无需重启程序）

编辑运行目录下 `setup.ini` 的 `[camera]` 节，添加/修改这三个键（默认值=不写也生效）：

```ini
[camera]
; 正面/反面工位的物理相机号（1-5），本机默认：4=相机四（夹尾正面）、5=相机五（夹尾反面）
frontCamNo=4
backCamNo=5
; 正面对应 PLC 哪个"实时"位：0=正面写DBX72.0（PLC的相机1实时）；改成1则正面写DBX72.1
realtimeBitFront=0
```

- 分不清正面是 PLC 说的"相机1"还是"相机2"：试跑实时取像观察 PLC 侧哪个位置位；对不上就把 `realtimeBitFront` 0 改 1，**重开相机设置界面即生效**。
- 正面/反面物理相机接反了：对调 `frontCamNo` 和 `backCamNo` 即可。

## 五、部署步骤

1. **备份**现场机旧版程序（惯例）。
2. 拷贝新编译产物到现场机运行目录（**至少这 4 个必须一起换**）：
   - `VisionMeasure.exe`、`CommonLib.dll`、`PLC监控.dll`、`SetCamera.dll`
   - 以及本次编译后时间戳变化的其他 bin 内 DLL（保险起见整个 bin 的 dll 都同步一遍）
3. 现场机程序以**管理员权限**启动（v6 起已内嵌 UAC 清单，双击会弹一次确认框；产线电脑若 UAC 设为"从不通知"则无弹窗）。
4. 确认启动日志出现 `构建标识: 2026-08-20-v7` 和 `WER LocalDumps 已启用`。
5. **PLC 程序同步更新**（见第三节），否则互锁不生效（日志会有节流警告提示）。

## 六、部署后验证清单

1. PLC 置 DBW232=4（或 M7070=4）→ 点菜单"相机设置"→ 弹"自动模式禁止"；日志出现 `【设备状态】`
2. 改回非 4 → 可进入相机设置 → 选相机4（正面）点"实时取像"→ PLC 侧观察 DBX72.0=TRUE；停止 → FALSE；选相机5 → DBX72.1 置位/复位
3. 实时取像进行中把设备状态切为 4 → 程序自动停止实时；相机设置开着时切 4 → 弹窗并自动关闭
4. 气缸翻位 → 日志出现 `【气缸状态】`（仅变化时输出）
5. 断网 30 秒再恢复 → 计数与结果发送不受影响（红线验证）

## 七、程序再"突然消失"怎么办

现场机跑一遍 `崩溃取证脚本.ps1`（仓库根目录），把桌面生成的"崩溃取证_时间"文件夹拷回开发。
